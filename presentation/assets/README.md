# Ảnh thực tế cho slide

Đặt ảnh screenshot thật vào thư mục này theo đúng tên dưới đây. Slide sẽ tự lấy ảnh từ các path này.

- `vinpearl-old-empty-state.png`: ảnh lỗi "Không có kết quả tìm kiếm phù hợp" của website/app Vinpearl cũ.
- `vinpearl-loading-or-no-flight.png`: ảnh lỗi loading hoặc không tìm được chuyến bay.
- `demo-qr.png`: ảnh QR dẫn tới link demo sản phẩm F2.

Nếu muốn dùng tên file khác, sửa trực tiếp thuộc tính `src` trong `presentation/index.html`.
