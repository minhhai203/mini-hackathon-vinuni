# F2 Vinpearl Presentation

Mở file `index.html` trong trình duyệt để present.

Điều khiển slide:

- Bấm mũi tên trái/phải trên màn hình.
- Dùng phím `ArrowLeft`, `ArrowRight`, hoặc `Space`.

Nội dung deck:

- Overview sản phẩm AI Travel Assistant.
- Pain point: không tìm được chuyến bay/khách sạn dù đã chọn khoảng thời gian rộng.
- Pain point: loading/lỗi khiến người dùng không thể thao tác tiếp.
- Lý do doanh nghiệp cần giải pháp.
- So sánh với website gốc/đối thủ.
- Cách F2 cải thiện website gốc Vinpearl.
- Kịch bản demo sau khi present.

Ảnh thực tế:

- Đặt screenshot vào thư mục `assets`.
- Các path đã được gắn sẵn trong slide:
  - `assets/vinpearl-old-empty-state.png`
